# Geluid

Sonificaties van de attention curve: de grafiek als partituur. Elke bron een stem, de acht jaar in dertig seconden. Regel zoals bij de tekening: alles wat je hoort komt uit de data; niets is sfeer.

## 2026-09-21-attention-tradwife.m4a

Tradwife, januari 2019 tot augustus 2026, 92 maanden in 30 seconden.
- **Wikipedia (vijf talen)**: een zachte toon; hoogte en volume volgen de opzoekingen (220–880 Hz).
- **Nederlandse Wikipedia**: een octaaf hoger, dun; klinkt pas als het artikel bestaat (mei 2024).
- **Google Trends**: een rietachtige stem, lager (110–440 Hz).
- **Onderzoek (OpenAlex)**: één lage puls aan het begin van elk jaar, zo sterk als het aandeel van dat jaar.
- **De zes momenten**: een korte bel op de maand (januari 2020, april/mei/juli/oktober/december 2024).
- **Het forum** (nog niet in de tekening, wel hier als proef): een ruis die vanaf 2021 langzaam dikker wordt en nooit piekt; gebruik, geen aandacht.

Gemaakt met een Python-script zonder bibliotheken (sinusvormen, per sample), omgezet met `afconvert`. Het script staat in de log van 21-09.
