# Beeldarchief

Renders en schermafbeeldingen van de site in ontwikkeling, met datum in de bestandsnaam. Buiten `content/`, dus niet op de site; wel in git, zodat het verslag zijn eigen archief heeft. Claude zet hier elke tussenstap neer die het bekijken waard was; Marieke voegt eigen screenshots toe (bijvoorbeeld van de telefoon, die Claude niet kan maken).

Van de radiale graph in opbouw (10–12 september 2026) bestaan alleen Mariekes eigen screenshots; de toestand van vóór de graph staat onder de git-tag `voor-radiale-graph-2026-09-12`.
